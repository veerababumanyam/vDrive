# Creating Your First Gallery

Learn how to create stunning client galleries that showcase your photography and impress your clients.

## Gallery Types

RawDrive supports different gallery types for various use cases:

### Proofing Gallery
Let clients select their favorite photos for editing or prints.

- Client can favorite and comment on photos
- Download disabled until selections are approved
- Great for wedding and portrait sessions

### Delivery Gallery
Share final edited photos with clients.

- Full-resolution downloads enabled
- Optional password protection
- Expiration dates for time-limited access

### Sales Gallery
Allow clients to purchase prints and products.

- Integrated with print partners
- Custom pricing per photo or package
- Automatic order fulfillment

## Creating a Gallery

### Step 1: Start a New Gallery

1. Click **New Gallery** in your dashboard
2. Enter a gallery name (e.g., "Smith Wedding - October 2026")
3. Select a gallery type
4. Choose a cover layout

### Step 2: Upload Photos

Drag and drop your photos or click to browse:

```
Supported: JPEG, PNG, HEIC, RAW
Max size: 100MB per file
Batch: Up to 500 photos
```

**Pro Tips:**
- Sort photos by filename before uploading
- Use descriptive filenames for easier organization
- Enable "Auto-rotate" to fix orientation

### Step 3: Customize Appearance

Make the gallery match your brand:

- **Theme**: Choose from Light, Dark, or Minimal layouts
- **Colors**: Set accent colors for buttons and highlights
- **Logo**: Add your studio watermark
- **Cover**: Select a hero image or slideshow

### Step 4: Configure Sharing

Set up how clients access the gallery:

| Setting | Options |
|---------|---------|
| Privacy | Public, Password, Invite Only |
| Downloads | Full-res, Web-only, None |
| Expiration | Never, 30/60/90 days, Custom |
| PIN | Optional 4-digit code |

### Step 5: Share with Clients

Once published, share your gallery:

- **Magic Link**: One-click access for clients
- **Email Invite**: Send directly from RawDrive
- **QR Code**: Print for in-person sharing

## Gallery Organization

### Albums

Group related photos into albums within a gallery:

- Wedding ceremony
- Reception
- Portraits
- Getting ready

### AI Auto-Albums

Let AI organize photos automatically:

- By faces (group by person)
- By scene (indoor/outdoor)
- By color palette

## Advanced Features

### Client Proofing

Enable proofing to let clients:

1. Mark favorites with a ❤️
2. Leave comments on specific photos
3. Submit their final selections
4. Receive their approved photos

### Face Recognition

Automatically group photos by the people in them:

- Clients find themselves instantly
- Great for large events
- Respects privacy settings

### Watermarking

Protect your work with smart watermarks:

- Text or logo watermarks
- Adjustable opacity and position
- Only on preview, not downloads
